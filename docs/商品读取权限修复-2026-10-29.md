# 商品读取权限恢复

2026-10-29，已修复并部署至支付宝云 healthmall（env-00jy6y52fd8l）。

原因：此前在公开商品 Schema 中增加了仅管理员可读的 `deleted_at`、`deleted_by`。小程序分类、详情等页面会读取完整商品，字段级权限使整次查询失败，出现 `PERMISSION_ERROR`。这是此前发布引入的回归，与图片 CDN 或微信密钥无关。

处理：

- 云端商品 Schema 撤回这两个字段定义，恢复原有公开商品读取；集合写入和删除权限保持禁止。
- 删除时间与操作者改存已有的私有集合 `jlg-goods-editor-requests`，商品表仅保留公开 `deleted` 状态；删除与审计仍在同一事务内执行。
- 公共模块已部署并同步更新云端依赖函数，Schema 与代码回读验证通过。源码同步到用户端主目录、当前 worktree 和管理端。
- 新增公开商品字段权限回归与私有审计断言，51 项交易回归、首页及详情回归通过；两端共享文件一致。

无需重新发布微信小程序，原客户端刷新即可使用修复后的云端权限。本次没有修改登录、微信或支付凭据。
