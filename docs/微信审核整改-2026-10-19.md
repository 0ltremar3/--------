# 微信小程序审核整改记录（2026-10-19）

本次依据用户提供的两张审核截图排查。代码修复、回归测试及微信发行编译已完成；尚未上传或重新提交审核，也未完成真机及正式云环境交易验收。

## 原因与修改

1. 协议外链：`uni_modules/uni-id-pages/config.js` 将协议指向旧静态托管 HTTP 地址，协议组件再通过 web-view 打开。截图中的文章 ID 与隐私政策配置完全一致。现改为导航到 `/jlg-use/problem/probileDetail?id=...`，在小程序内读取并渲染文章，游客可阅读。详情页补充加载、空内容和失败重试状态，关闭 mp-html 外链自动复制。
2. 强制登录：`pages.json` 的 `uniIdRouter.needLogin` 包含「我的」与商品分类，且微信登录页使用自定义导航、没有取消入口。现放开这两个页面；登录页增加「暂不登录，继续浏览」，清除当前登录回跳目标并回到首页，避免返回受保护页面再次触发登录。
3. 游客请求：个人中心原先在每次展示时无条件查询订单、会员及浏览记录。现刷新有效登录身份、重置私人页面数据，游客和过期会话不发起这些查询。分类页每次显示时同步身份，游客点击商品不写浏览记录。订单、地址等个人功能保留路由鉴权。
