# 微信开发者工具启动报 `[] [object Object]`

## 本次定位：工具会话与构建配置两层故障

环境：macOS，微信开发者工具 2.01.2510260，基础库 3.17.4。

开发者工具本地日志记录：

- `simulator launch catch error { code: 'ECONNRESET', port: 0 }`
- `appservice.js checkPluginInfo fail with error: [object Object]`
- `batchgetappattr` / `getpublibpercentage` 请求失败。
- 微信接口返回 `41001: access_token missing`，提示需要重新登录。

以上错误出现在开发者工具获取应用信息、插件配置和基础库配置阶段，早于商城业务代码启动；`[object Object]` 是工具把错误对象转换为字符串后的显示结果。

`cli islogin` 返回 true 仅说明本地存在登录状态。本次即使返回 true，微信服务仍拒绝请求，不能据此认定会话有效。同机 curl、系统 Node 和 HBuilderX 自带 Node 均能建立到 `https://servicewechat.com/` 的 TLS 连接（根路径返回404，属于正常HTTP响应）；故障集中在开发者工具连接/会话层，并非全机断网。

另发现源码 `manifest.json` 的 `mp-weixin.appid` 被设为 null，构建产物变为 `touristappid`，与此前项目实际 AppID 不一致。已从本次此前的构建配置核实并恢复为 `wx1fb49506c66ec500`，更新运行与发行产物。

## 白屏的业务层直接原因

重新扫码后，工具的接口鉴权错误消失，模拟器能够启动。但通过微信官方 miniprogram-automator 读取到首页初始化异常：

```text
TypeError: Cannot read property 'collection' of undefined
at pages/index/index.js
```

`uniCloud.database()` 返回 undefined，原因是此前直接执行 `plugins/uniapp-cli/bin/uniapp-cli.js` 没有注入 HBuilderX 关联的服务空间环境。代码语法和组件引用完整仍然可以编译成功，但无法使用默认 uniCloud 实例；此时首页 Vue 实例没有创建，模拟器表现为空白页或 appLaunch timeout。

已改用 HBuilderX 的正式发行入口，让 HBuilderX 自动读取现有服务空间关联并注入编译环境。没有在代码中硬编码客户端密钥或修改空间绑定。

本机 HBuilderX 5.07 CLI 的 `publish mp-weixin` 不传 `--appid` 时还会将 manifest.json 的微信AppID写成null。正式CLI命令必须显式传入已核实的项目AppID，不能只依赖源文件原值。

## 正确构建方法

在 HBuilderX 界面选择“运行到微信开发者工具”或“发行 → 小程序-微信”；命令行使用应用入口，且明确不上传：

```sh
/Applications/HBuilderX.app/Contents/MacOS/cli publish mp-weixin \
  --project '/Users/ryuchiang/Documents/ryuCodeLand/养生商城-用户端' \
  --appid wx1fb49506c66ec500 --upload false
```

运行版使用：

```sh
/Applications/HBuilderX.app/Contents/MacOS/cli launch mp-weixin \
  --project '/Users/ryuchiang/Documents/ryuCodeLand/养生商城-用户端' --compile true
```

新增 vue.config.js 构建防护：缺少、无效或多个默认云空间时直接失败，避免再次产出可编译但不能启动的包。执行 `node tests/mp-build-config.test.js` 验证防护。

## 已完成检查

运行版和发行版均通过50个页面、229处组件引用、116个 JavaScript 文件的完整性与语法检查；没有缺失组件或非法跨分包引用。发行主包约1698KB，低于2048KB限制。发行构建成功。

后续构建可执行：

```sh
node scripts/check-mp-runtime.js
node scripts/check-mp-runtime.js unpackage/dist/dev/mp-weixin
node scripts/check-mp-package-size.js
```

检查脚本会拒绝 AppID 与源码不一致、缺少云空间注入、缺少页面/组件文件、非法跨包组件或非法 JavaScript 语法。它不能验证开发者工具登录和真实业务运行。

## 后续遇到相同症状时的排查顺序

1. 在微信开发者工具中重新扫码登录，刷新微信侧会话；登录二维码只能由开发者本人确认。
2. 重新打开当前项目的 `unpackage/dist/build/mp-weixin` 或 HBuilderX生成的 `unpackage/dist/dev/mp-weixin`，确认项目AppID，不再改成游客模式来排查。
3. 点击编译，确认模拟器能进入首页。如果仍在 `batchgetappattr` / `getpublibpercentage` 阶段出现 `ECONNRESET`，检查开发者工具自己的代理设置（本次记录为SYSTEM，系统代理关闭），尝试在工具界面选择“不使用代理”后重开项目；勿清理微信用户数据或修改支付凭据。
4. 模拟器启动成功后再排查云函数调用。开发模式当前通过 `.hbuilderx/launch.json` 连接本地云函数，需保持HBuilderX本地调试服务；发行产物连接已部署云端。新增 `jlg-checkout` 等云函数尚未部署时，商品运费试算会报云对象不存在，这是启动恢复后的独立部署问题，不能靠修改AppID或前端运费解决。

用户重新扫码后已通过微信官方自动化接口进入首页，确认首页Vue实例创建，轮播与分类数据加载，截图可见真实首页内容。本次没有清除用户数据、修改系统网络设置、上传小程序或部署云函数。该运行验证不包含支付与下单。
